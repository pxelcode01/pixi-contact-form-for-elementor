== Installation ==

= Modern Way: =
1. Go to WordPress → Plugins
2. Search for "Pixi Contact Form"
3. Install in 1-click and activate

= Old Way: =
1. Upload `pixi-contact-form-for-elementor` to the `/wp-content/plugins/` directory
2. Activate the plugin through the Plugins menu in WordPress

== Frequently Asked Questions ==

= Does Pixi Contact Form work with all themes? =
Pixi Contact Form works with all themes that respect the coding standards set by the WordPress Codex. It is recommended to use Elementor's Hello Theme for full flexibility.

= How do I install this plugin? =
From your WordPress dashboard → Go to Plugins → Click on Add New → Search for "Pixi Contact Form" → Press Install → Click Activate.

= Is it necessary to install and activate Elementor? =
Yes. Elementor page builder must be activated on your platform.

= Is it necessary to install and activate Contact Form 7? =
Yes, if you want to use Contact Form 7 widgets. It must be activated on your platform.

= Is it necessary to install and activate Fluent Form? =
Yes, if you want to use Fluent Form widgets. It must be activated on your platform.

= Does it work with other page builders? =
No. It is only compatible with Elementor.

= Do I need to know how to code? =
No! Elementor provides all the widgets and features you need to build a professional website without any coding.
